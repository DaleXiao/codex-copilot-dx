# CCDX 1.4.12

## English

- Codex Auto review remembers saved settings, with an option to follow the observed conversation model and use low effort when supported.
- Antigravity can use a configured native Gemini API and set a separate Copilot response timeout. One-shot Copilot calls can return local input capacity after the upload finishes.
- The requests page keeps both activity visuals in place as rows change, shows the phase of a timeout, and retains a bounded 24-hour failure summary. The context chart keeps the unit and compression labels separate.
- Replayed MCP tool descriptions are checked by local masking without changing tool names or schemas.

Not verified: live native Gemini routing, real Codex Auto review, or whether a longer wait avoids Carbon timeouts.

## 简体中文

- Codex 自动审查会记住已保存的设置。可以跟随已确认的会话模型，并在支持时默认使用 Low。
- Antigravity 支持自定义原生 Gemini 来源，并且可以单独设置 Copilot 响应超时。不会重放的 Copilot 请求可在本机发送完成后腾出正文配额。
- 请求条目变化时，两处动效保持位置。错误详情显示超时阶段，并保留有上限的近 24 小时失败汇总。上下文图分开显示单位和压缩标签。
- 本地脱敏检查回传的 MCP 工具描述，保留工具名称和 Schema。

未验证：真实的原生 Gemini 路由和 Codex 自动审查，以及延长等待能否减少 Carbon 超时。
