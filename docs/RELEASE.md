# CCDX 1.4.0

- 统一 Codex、Claude 与 Antigravity 的上下文压缩调度。优先来源原生能力，在原生接口不可用或确认输入超限时，使用当前授权来源和模型进行有界兜底。
- 修复 Claude 压缩输入超限被转换成通用错误的问题，保留原生恢复所需的错误语义与推理档位。
- 压缩保留用户指令、签名状态和未完成工具调用。网关自产状态单独加密和校验，原生加密状态的脱敏映射可安全续接。
- 新增压缩状态与启停命令、设置开关和用量用途筛选。空推理项不再拆分并行工具调用；计数与生成的推理及工具控制保持一致。
- 修复 Windows 并发记录用量时，短暂锁文件访问冲突导致漏记的问题。减少脱敏请求的重复摘要计算，保持检测规则和缓存边界不变。

未验证：其他平台原生客户端和真实 Google 超限会话的完整压缩回放。
