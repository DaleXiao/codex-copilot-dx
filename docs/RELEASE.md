# CCDX 1.4.2

- 光束圆环成为默认动效。新增忙碌脉冲、疾速流光和装配流水线，保留格子进度条与关闭，移除轨道圆环和编织光场。
- 工具与代理活动沿用现有主题、布局和控件，短句即时跟随实际请求与工具状态。结果返回后收尾停止；取消、失败或状态断更时停止持续动效。
- 关闭动效仍保留状态文字。支持减少动态效果、隐藏及离屏暂停，不增加模型调用或轮询。
- 现有 `ccdx requests --active`、`ccdx requests tools` 与 TUI 请求菜单继续读取对应请求和工具元数据，文档同步更新。
- 动态加载工具的新定义可以覆盖旧定义，保留原有顺序、别名和工具选择限制。
- 同一来源的模型目录合并重复条目并补齐缺失信息，保留已有能力和禁用设置；旧缓存同步规范化。
- Chat 转换按来源声明保留缓存标记，消息顺序保持一致。加密代理任务在兼容重试中完整保留，避免任务正文被清理。

未验证：各平台原生客户端的完整工具执行回放及长期高并发绘制负载。
