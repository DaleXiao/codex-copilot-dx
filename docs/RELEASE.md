# CCDX 1.4.5

- Codex、Claude App、Antigravity 页面统一提供打开与切换应用入口；重新打开需确认，正常退出失败时不强制关闭。
- Codex 自动启动改为可选，默认关闭；手动打开和图片准备仍可独立使用。
- 本机接入检查结合当前进程与已有协议流量，不发送模型探测；无法确认时保留“接入待确认”。
- 多应用共享同一来源和账号的并发调节；按并发、速率、配额反馈分别等待，保留模型隔离和正在进行的回复。高级设置可限定并发上限；限流等待不重复延长，空闲后仍可按需恢复容量。
- 区分请求体内存和上游并发，修复未知长度请求长期占满内存预留的问题；取消、异常响应和压缩恢复及时释放额度，避免同一来源自排队。
- 来源导入可按需发现 CC Switch 和 Magpie 的本地 API 配置，生成待核对草稿；不复制密钥、不自动授权或选择模型。
- 吸纳上游的限流作用域、压缩请求输出上限和流终态处理经验；同步 CLI/TUI、帮助及使用文档。

性能说明：本版本在本机合成并发回放中的网关摊销耗时增加约 3.7%，不代表真实模型响应延迟。

未验证：真实上游限流、原生 App 完整接纳及长期负载。
